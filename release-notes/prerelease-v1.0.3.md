# 女娲Nuwax 1.0.3（Prerelease）

登录架构重构版：登录态统一以 nuwax webview 为唯一事实源，客户端壳不再维护独立登录体系；企业登录入口与多语言同步首次上线。

## 变更

### 登录态架构（webview 为唯一事实源）

- 客户端注册接口（reg）及壳侧后端调用统一注入 webview 登录凭证（Bearer）；登录成功自动完成「注册同步 → 重启本地服务」闭环；登出/凭证失效自动停服并清壳侧登录态。
- 移除壳内原生登录表单与初始化向导（SetupWizard），登录一律经 nuwax webview 登录页（含验证码登录，补齐其凭证同步）。
- 启动自动重连改为凭证优先判定；无界面部署（quickInit）凭据兼容保留。

### 企业登录

- 登录页新增「企业登录」入口：输入企业服务器域名，客户端切换域名并重新初始化（停服 → 重载新域登录页 → 登录后自动注册+拉起服务）；域名连通性预检防误配。

### 多语言

- **默认语言改为简体中文**（不再跟随操作系统语言）；曾在客户端内显式切换过语言的用户不受影响。
- nuwax webview 内的语言切换实时同步客户端壳界面（含设置弹窗等原生 UI）。

### 其他

- 修复：请求地址未拼配置域名导致的注册接口异常（相对路径/空域名兜底）。
- 修复：macOS 安装包签名失败（v1.0.0 / v1.0.2 已知问题）——依赖包内指向构建机的符号链接不再进入安装包，本版 macOS 签名应恢复。
- 客户端网络标识（UA）对齐产品：`@nuwax-ai/nuwax/<版本>`。
- 启动/初始化期间展示应用图标居中的全屏加载页。

## 升级须知

- 同前版：beta，Windows 包未签名，SmartScreen 可能告警；数据目录 `~/.nuwax` 与旧应用互不迁移。
- 后端注册接口的纯凭证（免密/免 key）注册待服务端放开：登出后重新登录的首个注册请求可能失败并提示「配置同步失败」，重试或等后端就绪后自动恢复，不影响登录本身。
- 语言偏好说明：登录后平台账号语言设置会同步到客户端（如账号设为 English 则客户端跟随）。
